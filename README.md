# Grid Forecaster – Neustart

Das alte Projekt einschließlich Daten, Skripten, Modellen und App liegt in
[archive/legacy_2026-10-20](archive/legacy_2026-10-20).
Hinweise zum Archiv stehen in [archive/README.md](archive/README.md).

Der Nutzer implementiert das neue Projekt selbst, beginnend mit einer Baseline.
Modellwahl, Datenquellen, Trainings-/Testmethode, Modellvergleiche und Maßnahmen
gegen Data Leakage sollen dabei fortlaufend dokumentiert werden.

Es ist keine neue Trainingspipeline eingerichtet. Die vom Assistenten vorzeitig
erstellten Skripte, Tests, aufbereiteten Daten, Modellparameter und Ergebnisse
wurden auf Wunsch entfernt.

Keine neue Datenaufbereitung, Implementierung oder Trainingsausführung durch
den Assistenten ohne ausdrücklichen Auftrag. Beratung und Dokumentation erfolgen
entsprechend der konkreten Frage des Nutzers.
